A fence park answered with `widen_paths` or "widen..." text widens the branch's paths by exactly the named files, records `{at, by, paths, answer, decision}` under `extra.widened`, clears the park and refusal, and returns the branch to green. The driver retries the merge on the same head without a new gate; if the head moved since the refusal, the branch goes to `reviewing` for a fresh gate first. Any other answer keeps the decision id on the branch, so a repeated refusal reopens the same decision row.
